# Screenshots

This directory contains screenshots related to the security audit.

Examples:

- OWASP ZAP interface
- Burp Suite request/response
- Authorized application testing
- OWASP Juice Shop testing
- Security findings
- Remediation verification

## Guidelines

Do not upload:

- Real user passwords
- Session tokens
- API keys
- Personal information
- Private customer data
- Confidential company information

Sensitive information should be removed or blurred before uploading screenshots.
